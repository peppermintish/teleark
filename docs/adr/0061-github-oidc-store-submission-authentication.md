# ADR 0061: GitHub OIDC for Store submission authentication

Status: Superseded by [ADR 0062](0062-msstore-submission-api-authentication.md) — 2026-09-30.

This record documents the short-lived decision to authenticate Microsoft Store CLI submissions with GitHub Actions OIDC. It is retained as historical context only. The CLI-based workflow and its federated-credential setup were removed; current authentication and delivery are defined by [ADR 0063](0063-independent-msix-store-delivery.md).
